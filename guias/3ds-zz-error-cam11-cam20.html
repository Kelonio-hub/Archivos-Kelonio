ERROR FBI : ERROR CAM (11) 0 (20)

⚠️ Importante: Este error está directamente relacionado con un fallo en la cámara de la consola al utilizar la aplicación FBI.

Por qué ocurre

  • Error 20: La cámara se ha desconectado o ha fallado repentinamente al intentar escanear un código QR.
  • Error 11: La cámara está rota, ya sea a nivel de software o de hardware.

  • Hacerse miembro Descargar Archivos

SOLUCIÓN 1: Descartar error de Software

  1. Restablece la consola usando el CTRNAND v1 para comprobar si el error de cámara es por software corrupto.
  2. Si tras realizar el restablecimiento la cámara sigue fallando, podría tratarse de un error de Hardware irremediable mediante software.

SOLUCIÓN 2: Evitar el uso de la cámara

  1. Probar con otros métodos de instalación manual (no remotos). Copia tus archivos `.cia` directamente en la tarjeta SD e instálalos desde el menú SD del FBI.
✅ Alternativa viable: Aunque tu cámara no funcione, puedes seguir usando la consola e instalar aplicaciones manualmente sin problema.

Si tienes más dudas o tu problema persiste, únete a nuestra comunidad de Discord para recibir asistencia personalizada.
