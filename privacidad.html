Política de privacidad

Última actualización: 20 de septiembre de 2026

Esta política explica cómo Kelonio trata los datos cuando utilizas la web de Kelonio y, en particular, cuando utilizas la función que comprueba la suscripción a un canal de YouTube para desbloquear determinadas guías.

1. Responsable y contacto

Proyecto: Kelonio
Correo de contacto: kelonioroms@gmail.com

Para cualquier consulta relacionada con privacidad o con el tratamiento de datos, puedes utilizar esa dirección de correo.

Importante: si para la publicación final de esta política necesitas identificar legalmente al titular con su nombre completo o sus datos de contacto adicionales, esos datos deben añadirse antes de enviar la aplicación a verificación de Google.

2. Datos a los que solicita acceso la función de YouTube

Cuando eliges verificar tu suscripción, Kelonio utiliza la autorización de Google para solicitar el alcance https://www.googleapis.com/auth/youtube.readonly.

Con ese permiso, la aplicación consulta la YouTube Data API para comprobar:

  • si la cuenta autenticada administra el canal de Kelonio; y
  • si la cuenta autenticada aparece suscrita al canal de Kelonio.

3. Cómo se utiliza la información

La información obtenida mediante la autorización de Google se utiliza únicamente para realizar esa comprobación de acceso y decidir si la guía correspondiente puede abrirse.

La aplicación no utiliza el permiso para publicar, modificar, borrar o crear contenido en YouTube y no suscribe automáticamente a la cuenta al canal.

4. Almacenamiento en el navegador

Después de una comprobación correcta, la web guarda en el almacenamiento local del navegador una indicación temporal de que el acceso ya fue verificado. Esa caché contiene datos técnicos necesarios para la validación local, como la fecha de verificación, el canal y el origen de la página. Su duración prevista es de 24 horas.

El token de acceso de Google utilizado durante la comprobación se mantiene en memoria durante la sesión de la página y no se guarda en esa caché local.

5. Proveedores y servicios externos

La función de acceso utiliza servicios de Google, incluidos Google Identity Services y YouTube Data API. La autenticación y el tratamiento realizado directamente por Google están sujetos a las políticas y condiciones de Google.

La web se publica mediante GitHub Pages. El funcionamiento de los servicios de GitHub se rige por las políticas y condiciones aplicables de GitHub.

6. No venta ni cesión comercial

Kelonio no vende los datos obtenidos mediante esta función a terceros. La aplicación no utiliza la autorización de YouTube para fines publicitarios propios.

7. Revocación del acceso

Puedes retirar en cualquier momento el permiso concedido a la aplicación desde la configuración de seguridad de tu cuenta de Google. Al retirar el permiso, Kelonio dejará de poder realizar nuevas comprobaciones de la suscripción hasta que autorices de nuevo el acceso necesario.

8. Seguridad y limitaciones

La web es una aplicación estática alojada en GitHub Pages. La caché del navegador es una optimización de funcionamiento y no constituye por sí misma una frontera de seguridad. El código de la aplicación puede ser examinado por cualquier persona que acceda al sitio.

9. Cambios en esta política

Esta política puede actualizarse para reflejar cambios en la aplicación, en sus servicios o en las obligaciones legales aplicables. La fecha de actualización se mostrará al principio de esta página.

10. Contacto

Para preguntas, solicitudes o incidencias relacionadas con privacidad, escribe a kelonioroms@gmail.com.
