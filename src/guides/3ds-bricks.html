Guía de Bricks y Pantallas Negras

⚠️ Importante: Identifica correctamente los síntomas de tu consola antes de aplicar una solución.

1. SEMIBRICK

  • El led Azul se apaga repentinamente.
  • La pantalla no se enciende.
  • NO se puede acceder a Luma ni a Godmode9.
  • NO se mostrará el Splash de Seguridad.

2. ARRANQUE ROTO / LUMABUG

  • El led Azul se mantiene encendido.
  • La pantalla de imagen Negra.
  • SÍ se puede acceder a Luma ni a Godmode9.
  • SÍ se mostrará el Splash de Seguridad.

SOLUCIÓN:
  • Quitar el cartucho de juego o R4 que se tuviera y probar su inicio.
  • Esperar alrededor de 15 minutos con la consola encendida.
  • Realizar pruebas scripts. [Contactar con Kelonio]

CÓDIGOS LED [X+Start+Select]:
  • Blanco: no carga el firm.
  • Rojo: firm corruptos.
  • Verde: carga bien firm de SD.
  • Amarillo: carga bien firm de Ctrnand.
  • Naranja: firm corrupto SD, carga Ctrnand.
  • Magenta: sin SD, firm corrupto Ctrnand.

3. BRICK NEGRO / BLACK SCREEN

  • El led Azul se mantiene encendido.
  • La pantalla de imagen Negra.
  • NO se puede acceder a Luma ni a Godmode9.
  • No se mostrará el Splash de Seguridad.

4. BRICK AZUL / ERROR BOOTROM

  • El led Azul se mantiene encendido.
  • La pantalla de imagen Azul.
  • NO se puede acceder a Luma ni a Godmode9.
  • No se mostrará el Splash de Seguridad.

5. BRICK FLEX / HARD BRICK

  • El led Azul se apaga abruptamente.
  • La pantalla no se enciende.
  • NO se puede acceder a Luma ni a Godmode9.
  • NO se mostrará el Splash de Seguridad.
  • Se escuchará "pop" o pertardeo metálico.

SOLUCIÓN: Llevarla a un técnico para que repare la conexión del Flex.
