NAND NDSI - BACKUP Y RESTORE

⚠️ ADVERTENCIAS:
- Si se fuerza la instalación de una NAND no correspondiente a la propia consola, podremos generar mayores problemas en la consola.
- Tras el proceso el firmware de la consola será el generado durante el respaldo, se deberá actualizar la consola si se precisa.

Requisitos

  • Consola Nintendo DSi con proceso de hackeo iniciado/terminado
  • Tarjeta SD donde realizar el respaldo
  • Archivos v1.1.1
    Hacerse miembro Descargar Archivos

APLICAR RESPALDO NAND (BACKUP) CUANDO:

  • Se termine de realizar el proceso de hackeo.
  • De forma periódica para asegurarnos que los juegos, programas y sus progresos tengan un respaldo.

APLICAR RESTAURACIÓN NAND (RESTORE) CUANDO:

Si el sistema de la consola presenta algún tipo de problema interno en sus rutas:

  1. Las App de fábrica lanzan error.
  2. Se presente algún problema de rendimiento funcional y no sea error de hardware (ejemplo: botón [B] no es reconocible).

NO APLICAR RESTAURACIÓN NAND CUANDO:

  • El error lo está generando un juego, el problema es el archivo utilizado y no el sistema hack.
✅ ¡Recuerda! Mantén siempre a salvo el archivo de tu NAND original en un ordenador o nube.

El respaldo es clave para la durabilidad del hackeo de tu consola.
