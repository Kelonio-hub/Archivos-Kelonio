Jugar Online en Wii U (Pretendo Network)

⚠️ Importante: El archivo Nimble permite conectarse a los servicios de Pretendo para servidores TIRAMISU, mientras que Inkay es exclusivo para servidores AROMA.

Requisitos

  • Tener una consola Wii U modificada con Tiramisu o Aroma.
  • Tener una cuenta en Pretendo Network.
  • Descargar el pack de conexión (Inkay/Nimble)
    Hacerse miembro Descargar Archivos

MÉTODO 1: Para usuarios de TIRAMISU (Nimble)

  1. Registra un usuario nuevo en la web oficial de Pretendo.
  2. Copia y pega el archivo nimble.rpx en la siguiente ruta de tu SD: wiiu\environments\tiramisu\modules\setup.
  3. En la consola, acude a Configuración de Usuario > Cambiar Usuario > Añadir Nuevo Usuario.
  4. Indica la ID y contraseña que hayas registrado en Pretendo.

MÉTODO 2: Para usuarios de AROMA (Inkay)

  1. Registra un usuario nuevo en la web oficial de Pretendo.
  2. Copia y pega el archivo inkay.wps en la siguiente ruta de tu SD: wiiu\environments\aroma\plugins\setup.
  3. En la consola, acude a Configuración de Usuario > Cambiar Usuario > Añadir Nuevo Usuario.
  4. Indica la ID y contraseña que hayas registrado en Pretendo.
✅ ¡Enhorabuena! Ya deberías tener acceso a los servidores online de Pretendo.
