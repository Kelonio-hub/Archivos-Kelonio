Eliminar Nintendo Network ID SIN Formatear

⚠️ Importante: Este proceso es muy útil si has olvidado o desconoces las credenciales de la cuenta Nintendo Network ID (NNID) vinculada a tu consola.

Requisitos

  • Consola de la familia 3DS programada con GodMode9.
  • Una PC o dispositivo para transferir el archivo a la memoria SD.
  • Archivo del Script (CRASH NETWORK.GM9)
    Hacerse miembro Descargar Archivos

PASO 1: Preparar la memoria SD

  1. Descarga el archivo desde el botón superior y extrae su contenido si está comprimido.
  2. Copia el archivo llamado CRASH NETWORK.gm9 y pégalo dentro de tu tarjeta SD en la ruta gm9/scripts/.

PASO 2: Ejecutar el Script en la consola

  1. Inserta la tarjeta SD en tu consola. Enciéndela manteniendo presionado el botón START para entrar a GodMode9. Luego, presiona el botón HOME, dirígete a la opción Scripts..., selecciona CRASH NETWORK y sigue las instrucciones en pantalla para confirmar la eliminación.
✅ ¡Enhorabuena! Has eliminado el perfil del Nintendo Network ID de la consola. Ya puedes iniciar sesión con otra cuenta o crear una nueva sin formatear.

Recuerda que esto solo desvincula el NNID de manera local; si recuerdas la contraseña más adelante, podrás volver a vincular la cuenta.
