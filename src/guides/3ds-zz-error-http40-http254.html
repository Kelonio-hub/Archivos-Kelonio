Error FBI: HTTP (40) o (254)

¿Por qué ocurre?

  • El servidor web que se está utilizando no tiene el archivo.
  • El servidor web que se está utilizando ha interrumpido la comunicación.

Solución

  1. Probar con otros servidores web.
  2. Probar con otros métodos de instalación manual (no remotos).

Esperamos que esta información te haya sido útil.
